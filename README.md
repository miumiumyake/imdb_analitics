# MovieLens Analytics

Аналитический отчет по датасету MovieLens с использованием самописного модуля.

## О работе

В рамках задания разработан модуль для анализа данных MovieLens и подготовлен аналитический отчет. Датасет включает информацию о фильмах, оценках пользователей, тегах и связях с IMDb. Для анализа использованы первые 1000 записей.

## Что сделано

1. **Разработан модуль movielens_analysis.py**
   - Созданы классы для работы с каждым файлом данных (Movies, Ratings, Tags, Links)
   - Реализованы методы для вычисления статистик, распределений, топ-списков
   - Весь необходимый функционал вынесен в модуль

2. **Написаны тесты (класс Tests)**
   - Проверка типов возвращаемых данных
   - Проверка корректности сортировки
   - Все методы протестированы через pytest

## Что проанализировано

**Фильмы**
- Распределение по годам выпуска
- Распределение по жанрам
- Фильмы с наибольшим количеством жанров

**IMDb-данные**
- Фильмы с максимальным рейтингом
- Самые плодовитые режиссёры
- Самые дорогие и самые прибыльные фильмы
- Самые длинные фильмы
- Стоимость одной минуты экранного времени

**Оценки пользователей**
- Распределение оценок по годам
- Распределение по шкале (от 0.5 до 5.0)
- Самые популярные и самые высокооценённые фильмы
- Спорные и поляризующие фильмы

**Пользователи**
- Распределение по активности (число поставленных оценок)
- Распределение по среднему баллу
- Пользователи с наибольшей дисперсией оценок

**Теги**
- Самые многословные и самые длинные теги
- Самые частотные теги
- Самые частотные слова в тегах
- Поиск тегов по ключевому слову

## Выводы

- **Драма и комедия** доминируют в датасете, занимая почти половину всех фильмов
- **Самые рейтинговые фильмы** не всегда совпадают с самыми популярными по числу оценок
- **Популярные фильмы** (много оценок) часто оказываются спорными (высокая дисперсия)
- **Поляризующие фильмы** выявляются только при учёте минимального числа оценок
- **Режиссёры-рекордсмены**: Хичкок (12 фильмов), Вуди Аллен (9), Спилберг (8)
- **Самый дорогой фильм** по бюджету и по стоимости минуты может не совпадать с самым прибыльным
- **Большинство пользователей** ставят мало оценок и придерживаются средних значений
- **Теги** показывают живую лексику пользователей (наиболее частотны "in netflix queue", "atmospheric", "superhero")
